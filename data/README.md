# Data inputs (not included in this repository)

The raw data are **not distributed** with this code because several files exceed
GitHub's 100 MB per-file limit (the largest is ~720 MB). To run the pipeline,
place the files below into this `data/` directory (or point the environment
variable `AUTOANTIBODY_DATA` at wherever they live).

## Required input files

| File | ~Size | Used by | Description |
|------|------:|---------|-------------|
| `downloads_study310_mapped_rpk_gene.csv` | 55 MB | `01_data_processing` | PhIP-seq reads-per-100k (RPK), gene-collapsed. Primary expression matrix. |
| `REAP_cancer_vaccine_butterfield.csv` | 2.7 MB | `01`, `06` | REAP autoantibody screen (Butterfield cohort). |
| `library_annotation.csv` | 642 KB | `01`, `06` | PhIP-seq phage library peptide/gene annotation. |
| `cancer vaccine Clinical Metadata.xlsx` | 18 KB | `01`, `06` | Clinical metadata (patient numbers, cancer status). |
| `09_021_Clinl_Final.Table_06122022.csv` | 1.8 KB | `01` | Final clinical outcome table (survival, response). |
| `df.csv` | 660 B | `01` | Gene-name repair table (genes mis-imported as dates, e.g. SEPT1). |
| `HPA_Gene_tissue_exprs/normal_tissue.tsv` | 83 MB | `05`, `07` | Human Protein Atlas normal-tissue expression. Public: proteinatlas.org/about/download |
| `HPA_Gene_tissue_exprs/pathology.tsv` | 22 MB | `05`, `07` | HPA pathology (cancer) expression. Public download. |
| `HPA_Gene_tissue_exprs/subcellular_location.tsv` | 1.8 MB | `05`, `07` | HPA subcellular localisation. Public download. |

## Intermediate objects (generated by the scripts, cached to avoid re-running upstream)

These are written by `01_data_processing` / `03_limma_*` and re-read downstream.
They are `.gitignore`d; regenerate them by running the producing script, or drop
your saved copies here.

| File | Produced by | Consumed by |
|------|-------------|-------------|
| `PHIPseq_list.Rda` | `01_data_processing` | `02`, `03`, `04`, `05` |
| `Row_sums_rpk_statistics.Rda` | `01_data_processing` | `01` (background selection) |
| `Pathway_results_list.Rda` | `03_limma_vaccine_induced_kinetics` | `03` |
| `genes_R2_R3.Rda` | `02` / `04` | downstream comparisons |

## Notes
- The Human Protein Atlas TSVs are public and can be re-downloaded from
  <https://www.proteinatlas.org/about/download>.
- The PhIP-seq and REAP data belong to the study authors; contact them for access.
- Two even larger raw files exist upstream but are **not needed** by this
  manuscript pipeline: `downloads_study310_mapped.csv` (486 MB) and
  `downloads_study310_mapped_rpk.csv` (722 MB) — the gene-collapsed RPK file is
  the only expression input used here.
